Essa aplicação foi gerada para que os alunos da disciplina Teste de Software possam gerar Testes de Unidade, Testes de Componentes e 
Testes de Integração a partir do exemplo dado em tests/test_funcao_familiar.py.
Para rodar o módulo de teste de funcao_familiar, digite no prompt:
python -m unittest tests/test_funcao_familiar.py
